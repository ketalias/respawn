# RESPAWN

Гейміфікація життя для всіх: 6 сфер (Тіло, Розум, Гроші, Спокій, Люди, Порядок), квести за XP, звертання «Він / Вона», дві фігури персонажа й 160+ скінів, нагороди за рівні сфер, збережені образи. Модулі за бажанням: бос місяця (гроші), журнал залу, фокус-сесії, розминка мозку. Статичний PWA без збірки — працює і як Telegram Mini App, і як звичайний сайт.

План і архітектура 2.0 (міграція збережень, майбутні друзі та спільні плани) — `docs/PLAN-v2.md`. Тести: `npm test`.

## Запуск локально

```bash
npm start          # http://localhost:5173
```

Демо-стан для перегляду (лише на localhost): `http://localhost:5173/?dev=seed&lv=12` — параметри дивись у `tools/dev.js`.

## Як закинути в Telegram-бота

1. Виклади папку на будь-який HTTPS-хостинг статики (GitHub Pages, Netlify, Vercel, Cloudflare Pages). Збирати нічого не треба — заливаєш як є.
2. У [@BotFather](https://t.me/BotFather): `/mybots` → твій бот → **Bot Settings → Menu Button → Configure menu button** → встав URL і назву кнопки.
   Або `/newapp` — отримаєш пряме посилання `t.me/<bot>/<app>`.
3. Після кожного оновлення міняй `VERSION` у `sw.js`, щоб офлайн-кеш оновився.

У Telegram прогрес дублюється в CloudStorage (синхронізація між пристроями), поза Telegram — лише в `localStorage`. У профілі є експорт/імпорт збереження.

## Структура

| Файл | Що всередині |
| --- | --- |
| `js/data.js` | Баланс і контент: рівні, ранги, атрибути, квести, бізнес-дії, скіни, ачівки |
| `js/money.js` | Екран «Гроші»: ціль місяця як бос, бізнес-дії, каса |
| `js/mind.js`, `js/drill.js` | Екран «Скіли»: фокус-сесії та міні-гра на усний рахунок (генератори задач) |
| `js/game.js` | Стан, збереження, правила гри |
| `js/sprite.js` | Процедурний піксельний персонаж (одяг, зачіски, аксесуари) |
| `js/scene.js` | Локації, аури, анімація сцени |
| `js/app.js`, `js/ui.js` | Екрани, іконки, звуки, конфеті |
| `tools/` | Генерація іконок (`npm run icons`), dev-хелпер, тести (`npm test`), `contact-sheet.html` — усі речі на фігурах A і B |

Новий скін = рядок у `ITEMS` (`data.js`) + функція малювання в `sprite.js`. Нова ачівка = рядок у `ACHS`. Бізнес-дії під свій бізнес — `BIZ_ACTS`, стартові квести — `STARTER_QUESTS`, нові типи задач — `GEN` у `drill.js`.
