# Бот RESPAWN у Telegram

## Рівень 1: налаштування в @BotFather (без коду)

`/mybots` → твій бот, далі:

| Що | Де в BotFather | Що вставити |
| --- | --- | --- |
| Опис у порожньому чаті (до /start) | Edit Bot → Edit Description | текст «Опис» нижче |
| Картинка над описом (640×360) | Edit Bot → Edit Description Picture | `docs/bot/description-640x360.png` |
| Коротко в профілі | Edit Bot → Edit About | текст «About» нижче |
| Аватар | Edit Bot → Edit Botpic | `icons/icon-512.png` |
| Кнопка біля поля вводу | Bot Settings → Menu Button | URL `https://ketalias.github.io/respawn/`, текст «Грати» |
| Кнопка «Відкрити» й галерея в профілі | Bot Settings → Configure Mini App → Enable | той самий URL + 3–5 скриншотів гри з телефона |

**Команди (/start, /help) поки не додавай.** Без сервера на них ніхто не відповість.

### Опис (до 512 символів)
```
RESPAWN — гейміфікація життя.

🎯 Квести у 6 сферах: Тіло, Розум, Гроші, Спокій, Люди, Порядок
⚡ XP, рівні, стрік і комбо — кожен день рахується
🧍 Піксельний персонаж еволюціонує разом з тобою: 160+ скінів, пети, аури, локації
💰 За бажанням: бос місяця для доходу, журнал залу, фокус-таймер

Тисни «Грати» 👇
```

### About (до 120 символів)
```
Твоє життя як гра: квести у 6 сферах, XP, стрік і персонаж, що росте разом з тобою.
```

## Рівень 2: бот, який пише сам (потрібен сервер)

| Фіча | Що робить |
| --- | --- |
| /start | Банер, 2–3 рядки про гру, кнопки «Грати» та «Як це працює» |
| Нагадування про стрік | О 20:00 за часом гравця, тільки якщо сьогодні 0 XP і стрік ≥ 2: «🔥 Стрік 9 днів згорить опівночі. Один квест — і він живий». Вмикається в Профілі |
| Підсумок тижня | Неділя ввечері: XP за тиждень, найсильніша сфера, стрік |
| «Поділитися» | Рівень чи ачівка картинкою в чат або сторіз, з посиланням на гру |

**Як влаштовано:**
- Cloudflare Worker (вебхук бота + розклад) і база D1. Безкоштовно.
- Цей самий сервер потім стане основою для друзів і спільних планів (етапи 8–10 у `PLAN-v2.md`).
- Гра надсилає серверу тільки мінімум: Telegram id, часовий пояс, останній активний день, стрік, XP по сферах за тиждень і налаштування нагадувань. Суми грошей і назви квестів не надсилаються.
- Запити перевіряються за підписом `initData`.
- Токен бота зберігається тільки в секретах Cloudflare, у коді його немає.
